# UV Evaluator

Модель для прогнозирования характеристик поглощения ультрафиолетового излучения сгенерированными молекулами.

Входные данные: молекулярная структура в формате SMILES.

Целевая характеристика: экспериментальный максимум поглощения (lambda_max, нм).

Базовая модель: регрессия на основе случайного леса (Random Forest) с использованием молекулярных отпечатков RDKit.
